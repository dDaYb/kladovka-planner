# Kladovka Planner

Браузерный планировщик кладовки: редактируемый план SVG, объёмная сцена WebGL, каталог стеллажей, велосипед и вертикальные подвесы для лыж.

## Возможности
- Общие координаты для 2D и 3D. Помещение 2860 × 1468/1779 мм, уступ 311 мм, потолок 3358 мм.
- Перетаскивание вдоль стен, редактирование ширины, глубины, высоты, отступа и высоты установки.
- Правый клик по объекту в 2D или 3D: поворот на 90°, создание копии рядом и удаление. Поворот сохраняет привязку к стене и отступ вдоль неё.
- Удаление выбранного объекта клавишей Delete/Backspace, кроме ввода текста и чисел.
- Проверка выхода за контур, пересечений по объёму и превышения потолка.
- Свободная площадь пола: объединение пересекающихся оснований, обрезанное контуром комнаты; подвесные объекты исключены из занятой площади пола.
- Просветы в двух сечениях не равны гарантированному непрерывному проходу.
- Автосохранение в браузере, импорт/экспорт JSON, ссылка на конкретную планировку, экспорт чертежа SVG и сметы.
- Библиотека Three.js 0.170.0 поставляется локально, без CDN и аналитики.

## Запуск

```sh
python -m http.server 8765
```

Открыть http://localhost:8765. Двойной щелчок по HTML через file:// не подходит для ES-модулей WebGL.

## Проверка

```sh
npm install
npx playwright install chromium
# В отдельном терминале запустить HTTP-сервер, затем:
npm test
```

Тесты проверяют геометрию, площади, пересечения, клавиатуру, сохранение и мобильную ширину. По умолчанию используется Chromium; для установленного Edge задайте BROWSER_CHANNEL=msedge.

## Допущения

Чертёж предварительный, не монтажная документация. Длина округлена с 2864 до 2860 мм. Участок 1463 согласован до 1466 мм для замыкания. Углы приняты прямыми. Вход 1077 мм — ориентировочный габарит вместе с наличниками, не чистый проход. Трасса трубы и открывание двери не установлены. Нижняя отметка трубы 3221 мм показана справочно, не как сплошное препятствие по всему потолку.

Габариты велосипеда и лыж примерные и редактируются. Форма велосипеда в 3D схематическая; расчёт использует огибающий прямоугольный объём. Для лыж предусмотрены отдельные вертикальные зоны: горные 250 × 220 × 1800 мм, беговые 180 × 160 × 2100 мм; крепёж выбирается под основание стены и снаряжение. Не совмещайте их с доступом к полкам или зоной снятия велосипеда.

Цены SE — из исходной сметы пользователя; альтернативные позиции сохранены из исходного планировщика и не являются актуальным коммерческим предложением. Данные проектов остаются в браузере. Общая ссылка содержит проект во фрагменте URL; делитесь ею только с нужными получателями.

### Велосипед и стремянка
- В свойствах велосипеда включается зона снятия в 2D и 3D. Для вертикального хранения глубина оценочного объёма — максимум глубины хранения и длины велосипеда плюс запас для человека. Верхняя граница — высота хранения плюс подъём с крюка. Зона направлена от выбранной стены.
- Красная зона означает выход за помещение, пересечение с другим предметом по высоте или недостаток высоты; бирюзовая — отсутствие этих конфликтов. Это консервативная оценка опускания прямо от стены, не расчёт траектории поворота и не гарантия выноса через дверь. Трасса трубы неизвестна.
- Начальные значения: длина велосипеда 1750 мм, место для человека 600 мм, подъём 150 мм. Они редактируются и сохраняются; зона не влияет на занятую площадь пола и смету.
- Каталог «Стремянка» содержит сложенную стремянку 500×120×1800 мм. Уточните габариты своей модели в панели свойств. Доступны поворот, копирование, привязка к стенам и высота подвеса.
- Детальная процедурная 3D-модель велосипеда содержит шины, обода, спицы, раму, вилку, руль, седло, цепь и педали. Она пропорционально вписана в габаритный контур; это типовой велосипед, а не обмерная копия конкретной модели.
